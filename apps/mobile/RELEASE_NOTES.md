## PayTsek V2 beta — 0.2.1

- Scans and imported screenshots now save as soon as PayTsek reads the amount. Wallet setup is no longer required.
- Choose which wallet notifications this phone listens to with simple switches in Settings.
- Connecting a separate payment phone is now an optional advanced action.
- Duplicate wallet entries are removed and prevented.
- Saved confirmations now appear briefly instead of occupying the screen.
- Back navigation and the remaining secondary screens have been rebuilt for a faster, clearer flow.

Notification matching remains supplementary evidence. When a notification has no shared receipt reference, PayTsek shows a possible match for review instead of claiming provider verification.
